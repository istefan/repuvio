Insigna de încredere {{brand}} („Evaluează-ne”) pentru site-ul tău WordPress.

== Description ==

Afișează pe site o insignă elegantă care trimite vizitatorii pe pagina ta de evaluare {{brand}}. Clienții mulțumiți ajung pe Google, iar cei nemulțumiți îți scriu privat.

* Plutitoare (dreapta-jos sau stânga-jos) sau în pagină prin shortcode `[repuvio_badge]`.
* Temă Light Monochrome sau Dark Slate.
* Afișare pe tot site-ul, doar pe prima pagină sau doar pe paginile alese, cu excluderi (ex: coș, checkout).
* Fără cookie-uri, fără tracking, fără apeluri externe: scriptul este inclus în plugin.

== Installation ==

1. În WordPress: Module → Adaugă nou → Încarcă modul → alege fișierul ZIP descărcat din {{brand}} → Instalează → Activează.
2. Mergi la Setări → {{brand}} Badge. Linkul paginii de evaluare și numele firmei sunt deja completate.
3. Alege poziția, tema și paginile, apoi apasă „Salvează setările”.
4. Opțional: adaugă `[repuvio_badge]` într-un bloc „Shortcode” pentru afișare în pagină.
